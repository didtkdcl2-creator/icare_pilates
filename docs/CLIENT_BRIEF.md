## 운영 연결 상태

기존 예약 문의는 localStorage에 저장되는 프로토타입. 이번에 추가한 설정·후기도 localStorage, 영상 파일은 IndexedDB에 저장됨. 같은 브라우저 로컬 미리보기 기능이며 실제 서버 업로드나 기기간 공유가 아님. 운영 로그인은 기존과 같이 Supabase Auth 연결이 필요. 공개 운영 전 Auth, Storage, DB 연동이 필요.
