## 운영 연결 상태

상담·체험수업 문의는 이메일 작성 화면 또는 카카오톡 오픈채팅으로 연결한다. 사이트는 신규 문의 내용을 저장하지 않는다. 고객이 선택한 앱에서 보내야 하며, 웹에서 발송 또는 접수 완료를 표시하지 않는다.

### 관리자 연결

- 로컬은 `npm run dev`로 시작한 뒤 `/admin.html`에서 **로컬 미리보기**를 선택한다. 이 모드에서 편집한 콘텐츠와 동영상 파일은 해당 브라우저에만 저장된다.
- 운영용 Supabase 프로젝트에서 두 SQL 마이그레이션을 순서대로 적용한다. 초기 스키마를 이미 적용한 필라테스 프로젝트에는 두 번째 마이그레이션만 적용한다. 기존 예약과 문의 테이블은 유지되지만 브라우저 API 접근 권한은 해제된다.
- Vercel에 `VITE_SUPABASE_URL`과 `VITE_SUPABASE_PUBLISHABLE_KEY`를 넣고 다시 배포한다. 비밀 키나 service-role 키는 브라우저 설정에 입력하지 않는다.
- Supabase Auth에서 관리자를 초대한 뒤 운영자가 신뢰할 수 있는 관리 도구로 해당 사용자의 UUID를 `profiles.id`에 등록한다. `owner`, `editor`는 영상·후기·FAQ·카카오톡 설정을 편집할 수 있고, `manager`는 FAQ만 편집할 수 있다. 권한 변경은 DB에서 수행하며, 브라우저에서 자기 권한을 바꿀 수 없다.
- 관리자만 사용하는 전용 Auth 프로젝트에서는 공개 가입을 끈다. 운영 연결 후 실제 계정으로 로그인과 로그아웃을 확인하고, 일반 계정으로 편집 요청이 거부되는지 점검한다. Supabase Security Advisor도 운영 프로젝트에 적용한 뒤 확인한다.
- 고객이 실제 카카오톡 오픈채팅 링크를 제공하면 관리자 **상담 채널**에서 저장한다.
